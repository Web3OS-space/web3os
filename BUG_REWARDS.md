# Bug reward ledger

First reporters of fixed bugs are recorded here by GitHub username and numeric GitHub user id. After mainnet launch the community votes on paying the whole list; paid coins are held back like every network reward and released under the same rule, which may take a long time and has no promised date. Recording is a commitment to record and to put the payment to a vote, not a guarantee. Rules: the section "Found a bug? Report it and earn coins" on https://web3os.space/

## Severity levels

- **Critical** 30,000 Web3OS: money miscounted or stolen, consensus split, encryption or privacy broken, remote control of someone else's node
- **High** 10,000: file lost or damaged, node crash it cannot recover from, reward paid to the wrong person
- **Medium** 2,000: feature broken with a workaround, error message that misleads users into a dangerous action
- **Low** 300: layout glitch, wrong text, small malfunction

Pre-mainnet reports are capped at 1,000,000 Web3OS in total.

Project team members and project accounts are not eligible. No payment to a party on a sanctions list; payment to US recipients waits for a legal opinion. Any tax on a reward is the recipient's own matter.

To claim after mainnet: put your GitHub username in your Web3OS profile and post your mainnet address in a comment on the issue from the GitHub account with the recorded user id. The address is then written into this ledger; the payout proposal names the commit of this file it pays, so check your row before the vote. A comment edited by anyone but its author is not a claim. For a report sent by email, name your GitHub account in the email; after the fix the project opens the issue and you claim there.
