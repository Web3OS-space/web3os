# web3os.space

**web3os.space is blockchain-based peer-to-peer (P2P) encrypted file storage.** Files are encrypted on your own device, split into pieces and kept on many ordinary computers around the world, so no single company owns them. Only content you have the right to share belongs here: uploading infringing or illegal content is forbidden (Terms 9.1), and a valid copyright notice removes it from every official access point (web3os.space/copyright); computers that deliver pieces quickly are paid in the project's coin, and the network checks each delivery (proof of fast delivery). Payments use one coin, **WEB3OS**, on the project's own chain, Web3OSChain.

**Testnet stage: the coin has no value and is not for sale; parameters may change. Nothing here is investment advice; digital assets are high-risk.**

## Take part

- Bugs: [open an issue](https://github.com/Web3OS-space/web3os/issues/new?template=bug_report.yml). The first reporter of a fixed bug is recorded in a public list by GitHub username; after mainnet launch the community votes on paying the list in WEB3OS, held back like every network reward, which is released under one rule with no promised date (a commitment to record and vote, not a guarantee). To be paid, post your mainnet address in a comment on your issue from the GitHub account recorded in the list. Security vulnerabilities are never posted in public: write to contact@web3os.space.
- Discussion: the Telegram group [t.me/Web3OS_Official](https://t.me/Web3OS_Official) (English). Sign-up for testers, attackers (try to cheat the test network from your own computer and accounts) and testnet miners: a private message to [@Web3OS_AI_bot](https://t.me/Web3OS_AI_bot).
- Contact (authorities, users, abuse, copyright, privacy): [`contact/`](contact/)

**Beware of scams.** Our only official accounts are the Telegram group above and @Web3OS_AI_bot, [@Web3OS_space](https://x.com/Web3OS_space) on X (news only) and mail addresses ending in @web3os.space. We never contact you first and never ask for recovery words, keys or money.
